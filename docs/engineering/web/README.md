# Web

`apps/web` is a single-page React app with hand-rolled URL parsing instead of a router, a WebSocket for the global board, and REST polling for org boards. [App Shell and Live Data](app-shell-and-live-data.md) covers routing, the data hooks, and the Vercel rewrite rules the routing depends on. [Profile Experience](profile-experience.md) covers the profile and story component trees, the card system, and the sponsor UI.
