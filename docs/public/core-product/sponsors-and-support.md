# Sponsors and Support

CCWarriors is free and open source. Sponsorships pay for the servers.

## Ways to sponsor

- **UPI / card** — [ccwarriors.xyz/#sponsor](https://ccwarriors.xyz/#sponsor) (Razorpay checkout, shown in USD).
- **Crypto** — ETH and Solana addresses on the same page.

Sponsor tiers run **Wood ($4) → Stone → Iron → Gold → Diamond → Netherite ($256)**, or any custom amount from $1 — every sponsor lands on the wall at [ccwarriors.xyz/#sponsor](https://ccwarriors.xyz/#sponsor), anonymously if you prefer.

GitHub Sponsors is pending verification and will join the list once live.
