# Profiles and Insights

Every warrior gets a [profile page](profile-pages.md) built from default sync data alone — rhythm, efficiency, GitHub footprint, the card. [Deep Insights and Stories](deep-insights.md) is the opt-in tier on top: behavioral insights, a Craft Score, and an LLM-written story page — each step consent-gated and reversible.
