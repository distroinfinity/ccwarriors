# CCWarriors

**Token burn rate, ranked.** CCWarriors is a live leaderboard of AI coding spend — Claude Code, Codex, Gemini, Copilot, and every other agent ccusage can read. See who's burning the most tokens, claim your rank, flex on the timeline. Free and open source, live at [ccwarriors.xyz](https://ccwarriors.xyz).

```bash
curl -fsSL https://ccwarriors.xyz/install.sh | bash
```

That's the whole onboarding: GitHub login opens in your browser, your usage is read locally, and you're on the board in under a minute.

By default, only raw token counts leave your machine — no code, no file names, no prompts, no dollar figures (the server does the pricing). Everything beyond that is opt-in, disclosed before it's sent, and reversible.

## The surfaces

- **The live board** — global top 100, re-sorting in real time, with per-tool filters.
- **Your profile** — `ccwarriors.xyz/<login>`: rhythm, efficiency grade, GitHub footprint, your card.
- **Deep insights and your story** — opt-in: Craft Score, working-style archetype, and an LLM-written story page.
- **Org boards** — your community's own co-branded board on a subdomain.
- **The README badge** — your live rank in your GitHub profile.
