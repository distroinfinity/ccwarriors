# Privacy and Trust

Two promises hold this product up. First: default mode sends token counts and nothing else — every step beyond that is opt-in, disclosed in plain text before anything is sent. [What Leaves Your Machine](privacy-model.md) is the exact inventory. Second: the server distrusts every number a client sends — it prices tokens itself and quarantines anything implausible. [Fairness and Plausibility](fairness-and-plausibility.md) explains how.
